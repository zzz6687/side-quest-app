# SideQuest 🎯

Веб-приложение для мотивации пользователей к новым активностям через систему случайных заданий с фотоподтверждением и геймификацией.

## 🌐 Демо

- https://side-quest-app1.vercel.app/

## 📱 О проекте

SideQuest помогает людям выйти из рутины. Пользователь получает случайное задание, выполняет его в реальной жизни, фотографирует результат и отправляет на проверку. После одобрения администратором начисляются очки и повышается уровень.

### Как это работает:
1. Получи случайный квест из базы 100+ заданий
2. Выполни задание и сфотографируй результат
3. Отправь фото на проверку администратору
4. Получи очки и повышай уровень

### Типы заданий:
- 🌿 **Outdoor** — прогулки, природа, городские активности
- 🏠 **Indoor** — творчество, кулинария, саморазвитие

### Система уровней:
| Очки | Уровень |
|------|---------|
| 0–49 | 🌱 Новичок |
| 50–99 | 🧭 Искатель |
| 100–149 | ⚡ Опытный |
| 150–199 | 🏆 Мастер |
| 200+ | ✦ Легенда |
